# Сравнительный стенд СУБД: PostgreSQL, SQLite, MySQL, MongoDB, MsSQL, Oracle

Веб-приложение для сравнительного анализа производительности шести СУБД на операциях CRUD (Create, Read, Update, Delete) с набором из 1000 записей пользователей, замером времени отклика (в миллисекундах с микросекундной точностью) и визуализацией на интерактивных графиках в реальном времени.

---

## 🏗 Архитектура проекта

* **Бэкенд:** Python FastAPI (`app/main.py`)
  * Замер скорости выполнения запросов с помощью `time.perf_counter()`
  * Единый интерфейс доступа к 6 базам данных (`app/databases/manager.py`)
* **Фронтенд:** Интерактивный SPA-дашборд (`app/static/`)
  * **Tailwind CSS** — современный дизайн и адаптивная верстка
  * **Chart.js** — динамические столбчатые диаграммы (скорость последней операции + средняя скорость по типам запросов)
  * **Lucide Icons** — иконки статусов и действий
* **Базы данных (6 СУБД):**
  1. **SQLite 3** — локальная файловая БД (`data/benchmark.db`)
  2. **PostgreSQL 16** (Docker: порт `5432`)
  3. **MySQL 8.4** (Docker: порт `3306`)
  4. **MongoDB 7.0** (Docker: порт `27017`)
  5. **Microsoft SQL Server 2022** (Docker: порт `1433`)
  6. **Oracle Database 23ai Free** (Docker: порт `1521`, драйвер python-oracledb Thin Mode)

## 🚀 Пошаговый запуск через Docker

### Шаг 1. Убедитесь, что Docker Desktop запущен
Проверьте, что в трее Windows запущен **Docker Desktop**.

### Шаг 2. Запуск всех сервисов одной командой
В терминале в папке `d:\DataBaseProject` выполните:

```powershell
docker compose up --build -d
```

> **Примечание по инициализации:**
> Контейнеры **PostgreSQL**, **MySQL**, **MongoDB** и **SQLite** стартуют за пару секунд.
> Контейнерам **MsSQL** и **Oracle Database** при первом «холодном» старте требуется около 30–60 секунд для создания системных файлов базы данных.
> Статусы их готовности в реальном времени отображаются на сайте в верхней строке.

### Шаг 3. Открытие веб-интерфейса
Откройте браузер по адресу:
👉 **[http://localhost:8000](http://localhost:8000)**

## 📊 Возможности веб-интерфейса

1. **Заполнение 1000 записей (Кнопка «Заполнить 1000 записей»):**
   * Генерирует 1000 идентичных русскоязычных записей (ФИО, Должность, Отдел, Зарплата) с фиксированным сидом (`ru_RU`) и синхронно загружает их во все 6 баз данных.
2. **Интерактивные графики Chart.js:**
   * **График 1:** Отображает время последней операции (в мс) для каждой из 6 баз данных.
   * **График 2:** Сводная диаграмма средней скорости по операциям `SELECT`, `INSERT`, `UPDATE`, `DELETE`.
3. **Поиск (SELECT):**
   * Введите в поле поиска ФИО или должность (например, *«Иванов»*, *«Backend»*, *«QA»*) — приложение выполнит поиск и отобразит скорость выполнения запроса по каждой БД.
4. **Добавление (INSERT):**
   * Кнопка «Добавить запись» позволяет создать пользователя в одной выбранной СУБД или сразу во всех 6 СУБД с замером времени вставки.
5. **Редактирование (UPDATE):**
   * Кнопка с иконкой карандаша в таблице позволяет изменить ФИО, должность, отдел или зарплату.
6. **Удаление (DELETE):**
   * Кнопка с иконкой корзины удаляет запись и фиксирует задержку операции.
7. **Пакетный бенчмарк:**
   * Кнопка «Запустить бенчмарк» автоматически выполняет серию из десятков операций чтения, вставки, обновления и удаления на всех СУБД и пересчитывает средние показатели.
8. **Вкладка «Логи и статистика»:**
   * Полная история операций с меткой времени, типом команды, именем СУБД и миллисекундами.

## 🛠 Полезные команды Docker

* Просмотр работающих контейнеров:
  ```powershell
  docker compose ps
  ```
* Просмотр логов веб-сервера или СУБД:
  ```powershell
  docker compose logs -f web
  docker compose logs -f oracle
  docker compose logs -f mssql
  ```
* Остановка всех контейнеров:
  ```powershell
  docker compose down
  ```
* Запуск консольного сидинга внутри контейнера:
  ```powershell
  docker compose exec web python scripts/seed.py --count 1000 --db all
  ```
